// Quick Start

快速开始

两步装好，立刻使用

① 克隆仓库

terminal
git clone https://github.com/Glen-Wei/headhunter-skills.git ~/wb-skills

② 安装 Skill（WorkBuddy 用户）

terminal
cp -R ~/wb-skills/* ~/.workbuddy/skills/

其他 AI 助手：把对应 skill 目录放入你的 skills 目录（如 ~/.claude/skills/），或直接阅读各 skill 的 SKILL.md。
